Project · AICTE – IBM SkillsBuild

Zenith AI — Mental Health Chatbot

PythonStreamlitscikit-learnTF-IDFOpenAI APIDocker

Problem

Many students want a private, always-available place to talk through stress and build small daily habits. Zenith explores how a lightweight NLP model and an LLM can offer supportive, practical replies, with a clear path to help when someone may be in crisis.

Key features

  • Chat with conversation history
  • Mood tracking and daily wellness goals
  • Guided breathing and journaling pages
  • Daily affirmation and a streak system
  • Emergency override that returns crisis resources

Implementation

  • TF-IDF vectoriser with cosine similarity picks guidance from a trained response set
  • The guidance is passed silently to an OpenAI model, which writes the reply in a calm, human tone
  • If the model is unavailable, a gentle fallback reply is returned
  • Multi-page Streamlit interface; Dockerfile included

Project · Full-stack web application

Smart Design Brief Generator

Node.jsExpressJavaScriptGroq APIHugging FaceREST API

Problem

Writing a clear design brief is slow and often inconsistent. This app asks for a few project details and returns a structured, professional brief that a designer can start from straight away.

Key features

  • Project input form (name, brand, industry, design type, style, audience, language)
  • LLM-generated brief returned as structured JSON
  • PDF export of the result
  • Translation of the brief into other languages
  • Chat assistant for follow-up questions
  • Optional reference-image upload and AI image generation

Implementation

  • Express REST API with endpoints for generate, translate, chat and image generation
  • Groq-hosted LLM with automatic model fallback on rate limits
  • Response cleaning and JSON parsing with structured error replies
  • Image uploads handled with Multer (size and type limited)

Project · Flask web application

AI Image Transformation Tool

PythonFlaskOpenCVSQLAlchemySQLiteFlask-Login

Problem

Turning a photo into a cartoon, sketch or painting normally needs design software. This app lets a signed-in user upload a photo, pick a style and download the result in seconds.

Key features

  • Five styles: Cartoonized, Anime, Oil Painting, Pencil Sketch, Realistic
  • User registration and login
  • Per-user usage quota with an upgrade prompt
  • "Your Works" gallery of past results
  • Admin dashboard for managing users
  • Star-rating and review feedback form

Implementation

  • OpenCV image-processing pipelines, one per style
  • Flask with Flask-Login sessions and password hashing
  • SQLAlchemy models on SQLite for users, quotas and feedback
  • Upload validation: PNG, JPG, JPEG or GIF only, 16 MB limit, per-user storage folders
  • Background processing for image jobs
